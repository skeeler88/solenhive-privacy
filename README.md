# SolenHive privacy policy host

Public HTTPS source for Google Play **App content → Privacy policy** and in-app `Legal:PrivacyPolicyUrl`.

| URL | Use |
|-----|-----|
| https://cdn.jsdelivr.net/gh/skeeler88/solenhive-privacy@main/privacy-policy.html | Play Console + app (recommended default) |
| https://skeeler88.github.io/solenhive-privacy/ | After enabling GitHub Pages (Settings → Pages → branch `main` / root) |
| https://raw.githubusercontent.com/skeeler88/solenhive-privacy/main/privacy-policy.html | Raw fallback |

Keep in sync with the main app repo file `docs/play/privacy-policy.html`.
